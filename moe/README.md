# MoE calibration update 2026.07.10-12

Updated 2026-09-14 (UTC). The pack starts 2026-07-10. Compared with `2026.09.14-1`.

## Rules

- Base DPM: 1,559 → 1,700 (+9.0%)
- Max enemy bots: 50% → 30% (5v5 up to 1, 10v10 up to 3 bots; battles over it don't count)
- Progress %: now runs straight to the mark lines (65% = mark 1, 85% = mark 2, 95% = mark 3). Every battle moves it in proportion to how good it was, from a tank's first battle. Marks themselves are unchanged
