# HEAT Labs images

Images for the HEAT Sentinel page on [HEAT Labs Mods](https://github.com/HEATLabs/HEAT-Labs-Mods) (`mod-files/sentinel.md`). The page links them by raw URL, so keep the file names stable.

| File | Used as |
|------|---------|
| `banner.webp` | `page-image` (same as `docs/banner.webp`). Animated, plays once. Built by `heat-tray/scripts/readme-media/startup-banner.mjs --publish` |
| `stats-overview.webp` | Overview image 1: Battles, Overview |
| `rivals-1v1.webp` | Overview image 2: Battles, 1v1 |
| `loadouts.webp` | Overview image 3: Battles, Loadouts |
| `moe.webp` | Overview image 4: Battles, MOE |

The four overview images are `docs/screenshots/` shots (`battles-overview`, `rivals`, `loadouts`, `moe`) converted to WebP, quality 88. After a reshoot, convert them again.
